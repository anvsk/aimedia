# v0.2 Native Live Pipe

`v0.2-native-live-pipe` 是 aimedia 第一个可以完成真实用户闭环的预发布版本：在
Linux x86_64 + NVIDIA GPU 上，不依赖 FFmpeg/libav 运行时，接收一路
SRT/MPEG-TS H.264/AAC，原生解码、重新计时、重新编码并输出一路 SRT/MPEG-TS。

## 可以使用的范围

- SRT caller/listener 输入和输出，libsrt 1.5.5；
- MPEG-TS、H.264 Main 8-bit 4:2:0、无 B 帧、最高 1080p30；
- AAC-LC、48kHz、双声道、128kbps；
- NVDEC + NVENC，独立单调节目时钟；
- 输入断流保留最后健康画面并输出静音，恢复后等待 IDR；
- 输出断线不累计历史包，恢复后重发 PAT/PMT 并请求 IDR；
- `aimedia explain`、`probe`、`doctor`、`control state --json` 和有界队列指标。

## 发布证据

- FFmpeg、OBS 输入与 ffprobe、VLC、OBS 输出互操作；
- SRT caller/listener 四种组合；
- 1% 丢包、20ms 抖动、40ms RTT 和损坏 TS 恢复；
- 延迟 4 秒连接输出端时零视频丢帧、NVDEC surface 高水位 3/4；
- RTX 5060 Laptop + 577.12 驱动的 1080p30 两小时运行：p50 134ms、p95 173ms，
  PTS/DTS/PCR 零倒退，RSS 首尾窗口 +2.5MiB，设备显存 178→178MiB；
- 运行镜像没有 `ffmpeg`、`ffprobe` 或 `libav*` 依赖。

## 构建与运行

参考 [GPU Docker 说明](../../docker/README.md)构建运行镜像，然后使用
`examples/single-srt.yaml`：

```bash
docker run --rm --gpus all \
  -e NVIDIA_DRIVER_CAPABILITIES=compute,utility,video \
  -v "$PWD/examples:/work:ro" \
  aimedia:gpu run -f /work/single-srt.yaml
```

完整门禁可以复现：

```powershell
pwsh ./tools/soak.ps1 `
  -EngineImage aimedia:gpu `
  -PeerImage aimedia:test-tools `
  -DurationSeconds 7200
```

## 已知边界

- 这是 Alpha 预发布，不是完整 FFmpeg 替代；
- 不支持 RTMP/RTMPS、RTSP/RTP、H.265、缩放、变帧率、多输出或双路真实数据面；
- 只完成 RTX 5060 Laptop 实测，NVIDIA L4 尚未验证；
- 这次是两小时门禁，24 小时生产 soak 留在 Beta 路线；
- H.264/AAC 商业分发仍需独立专利与地区法律评估。
